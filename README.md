# Hotbar Customizer

FF14標準ホットバーのアイコン表示をカスタマイズするDalamudプラグインです。

## 主な機能

- 通常ホットバー / 通常XHBのアイコン画像差し替え
- QuickPanelの5×5内移動追従
- FFXIV標準アイコン / Dalamudプラグインアイコン / 任意画像を使用可能
- アイコン上への文字オーバーレイ（複数行対応）
- ホットバー単位の表示 / 非表示、透過調整
- タイトルバーからOFUSE支援ページを開くハートボタン

## 注意事項

- 拡張クロスホットバー（WXHB）の画像変更には対応していません。
- QuickPanelは5×5内の移動のみ追従します。
- 同じ項目が他の場所に配置されていても自動反映しません。
- ホットバーやマクロの保存データ自体は変更しません。

## コマンド

- `/hvc` : 設定画面を開く
- `/hvc panel` : ホットバー操作バーを表示
